# cs2114-project1-groupNN
Small Text Adventure Game - How to Slay Your Dragon

1. **Clone the repository and navigate into the folder:**
   ```bash
   git clone <https://github.com/julian252026s/cs2114-project1-groupNN>
   cd <cs2114-project1-groupNN>
   ```

2. **Compile the source code:**
   ```bash
   javac Game.java
   ```
   *(Note: AdventureGame.java also works).*

3. **Run the program:**
   ```bash
   java Main
   ```
